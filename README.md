Ky projekt është një faqe statike biznesi e zhvilluar në kuadër të një detyre të lëndës së programimit web.
Faqja është ndërtuar duke përdorur HTML dhe CSS, me qëllim simulimin e një website profesional për një kompani.

Karakteristikat
Strukturë responsive me disa faqe
- Navigation bar funksional në të gjitha faqet
- Faqe të dedikuara për:
Home
About
Projects
Contact
- Stilizim i centralizuar me CSS të jashtëm
- Organizim i qartë i file-ve dhe folderëve

Teknologjitë e Përdorura
- HTML5
- CSS3

Struktura e Projektit
project_web/
│
├── index.html
├── about.html
├── projects.html
├── contact.html
│
├── styles/
│ └── style.css

Qëllimi i këtij projekti është të demonstrohet dhe praktikohet:
- Krijimi i strukturës bazë të një website me HTML
- Stilizimi dhe layout-i i faqeve me CSS
- Ndërtimi i navigimit ndërmjet disa faqeve
- Organizimi korrekt i një projekti web
- Krijimi i një interface të pastër dhe funksionale për përdoruesin
